# 去厨房整点吃的 · 单文件版

> 勾一勾家里现有的食材，立刻知道今天能做什么菜。**纯前端、零安装、可完全离线**，一个 HTML 文件就是整个应用。

---

## 📦 使用说明

- 文件：`去厨房整点吃的.html`（约 8 MB）
- 使用：**双击文件**即可在浏览器中打开使用，无需安装、无需联网、无需任何其他文件
- 分发：把本 HTML 连同本 README 一起发送即可，对方双击即用
- 已选食材自动保存在浏览器本地（localStorage），关闭再打开仍在

## ✨ 功能简介

- **🧺 食材选择器**：11 类食材分组 + 搜索 + 自定义输入；油盐酱醋葱姜蒜视为家中常备、不用勾
- **🎯 三档推荐引擎**：按每道菜的"核心配料"判定——
  - ✅ **可以做**：核心配料全齐
  - ⚠️ **差一点**：缺 1～2 样主料，列出缺什么，按匹配度排序
  - 🔒 **缺太多**：折叠展示
  - 未选食材时：随机推荐 + 换一批 / 上一批
  - 📖 浏览全部菜品：198 道全量 + 16 个分类筛选
- **🍳 菜品详情页**：成品大图、配料原文清单（✅ 已有 / ❌ 缺 / 👌 常备 / 🧪 专用料包 + 家常替代）、门店批量参数 + 家用换算提示条、步骤编号 + 动作 emoji、品类说明、官方视频
- 全站克制动效、PC/平板/手机全端自适应、"减弱动效"无障碍降级

## 🔧 技术说明

- 纯前端静态应用（React 单页应用），无后端、无网络请求（官方视频外链除外，离线时该区域留空）
- 全部代码（HTML/CSS/JS）与 179 张菜品图片（base64 内联）已打包进**单一个 HTML 文件**
- 对应源码项目位于 `cook-select/`（Vite + React + TypeScript），数据重建管线见其 `scripts/` 与 README
